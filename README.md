## What it does

`main.py` writes a single-line weather forecast for the invented city of
Blorptown to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, or
`/output` by default). The forecast borrows the flat phrasing of an official
weather bulletin — percentage chances and all — then breaks it with frogs
and a mayor who blames the clouds. Python standard library only, fully
deterministic: the same line every run.
